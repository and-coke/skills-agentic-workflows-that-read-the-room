## Latest GitHub Updates

### GitHub Copilot

- **Copilot code review: Agent skills and MCP now generally available** — Copilot code review can now use agent skills and Model Context Protocol (MCP) tools during reviews, giving it richer context. *(Source: [GitHub Changelog, Jul 29 2026](https://github.blog/changelog/2026-07-29-copilot-code-review-agent-skills-and-mcp-now-generally-available))*
- **Grok 4.5 now available in GitHub Copilot** — xAI's Grok 4.5 model is available as a selectable model in Copilot Chat. *(Source: [GitHub Changelog, Jul 28 2026](https://github.blog/changelog/2026-07-28-grok-4-5-is-now-available-in-github-copilot))*
- **Default model enablement for Copilot Business and Enterprise** — Admins can now set a default AI model for their organization. *(Source: [GitHub Changelog, Jul 29 2026](https://github.blog/changelog/2026-07-29-default-model-enablement-for-copilot-business-and-enterprise))*
- **Enterprise managed settings in the GitHub Copilot app** — Enterprise policies now apply to the Copilot app and Copilot cloud agent, giving IT admins centralized control. *(Source: [GitHub Changelog, Jul 27 2026](https://github.blog/changelog/2026-07-27-enterprise-managed-settings-now-apply-to-the-github-copilot-app))*
- **Automating cross-repo documentation with GitHub Agentic Workflows** — A practical guide to using Copilot agentic workflows to keep docs in sync across repositories. *(Source: [GitHub Blog](https://github.blog/latest/))*

### Supply Chain & Security

- **npm publish-time malware scanning** — npm now scans packages for malware at publish time and surfaces dual-use metadata to help catch supply chain attacks early. *(Source: [GitHub Changelog, Jul 28 2026](https://github.blog/changelog/2026-07-28-npm-publish-time-malware-scanning-and-dual-use-metadata))*
- **GitHub Actions holds potentially malicious workflows for approval** — Workflows triggered by first-time or suspicious contributors are now held for maintainer approval before running. *(Source: [GitHub Changelog, Jul 28 2026](https://github.blog/changelog/2026-07-28-github-actions-holds-potentially-malicious-workflows-for-approval))*
- **Dependabot alerts on malicious packages across more ecosystems** — Dependabot now detects known-malicious packages in additional package ecosystems. *(Source: [GitHub Changelog, Jul 28 2026](https://github.blog/changelog/2026-07-28-dependabot-alerts-on-malicious-packages-across-more-ecosystems))*

### Dependabot Tips

- **Group Dependabot updates and control cadence** — You can now group related dependency updates together and slow the update cadence while keeping security fixes fast. See the [GitHub Blog post](https://github.blog/latest/) for configuration examples.
